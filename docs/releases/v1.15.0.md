# zouk v1.15.0

## Menu bar application-menu title now reads "Zouk"

The bold title next to the Apple logo (top-left of the menu bar) read lowercase "zouk" even though the items inside that menu (About Zouk/Hide Zouk/Quit Zouk) already read "Zouk." That title is driven by `CFBundleName`, a separate key from `CFBundleDisplayName` (which already covers the Dock/Cmd+Tab/Force Quit surfaces) -- fixed by setting `CFBundleName` to "Zouk" too.

## Packaging fix: `make bundle` no longer leaves a stale code signature behind

`make bundle` used to only overwrite individual files inside `.build/zouk.app`, never removing the whole bundle first. A bundle previously produced by `make sign`/`make pkg` could end up with a leftover, mismatched `Contents/_CodeSignature` after a later unsigned rebuild -- which made macOS refuse to launch it at all. `bundle` now wipes the app bundle before rebuilding it, every time.

No other user-facing changes.
