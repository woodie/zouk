# zouk v1.17.0

## Upload files

Drag files from Finder onto the window, or click the new upload button at
the right of the toolbar and pick them. Each file is sent with WebDAV `PUT`
under its own name, up to 25 MB each (lambada's limit). Folders and bigger
files are skipped with a short message saying why, and if a file with the
same name is already there, zouk asks before replacing it. Afterward the
list reloads and the new file is selected.

## Pictures get real thumbnails

Uploads aren't always PDFs, so pictures now show as thumbnails too, in
their own shape: a wide screenshot is a wide thumbnail, not a strip on a
tall page, and the selection halo hugs it.

## Deleting from two places at once

If a file was already deleted from another app or the web page, deleting it
in zouk now just removes it, instead of failing and leaving its thumbnail
behind. Any other failed delete reloads the list, so it shows what's really
on the server.

## Smaller changes

- The delete confirmation names the file ("Delete notes.pdf?"), and the
  footer counts files ("1 file", "12 files"), matching lambada's web page.
- An empty folder says "No files yet. Drop files here to upload."
