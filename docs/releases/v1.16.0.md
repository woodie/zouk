# zouk v1.16.0

## Works with any WebDAV folder that allows guest access

zouk now lists the server's folder with standard WebDAV (`PROPFIND`)
instead of lambada-web's `files.json`, then downloads and deletes each
file at its own address. Enter the folder's address, like `10.0.1.111`
or `10.0.1.111:8081/scans/`. lambada is moving to nginx WebDAV
(woodie/lambada#21), and NAS shares and other guest-access WebDAV
servers work too.

Until lambada-web is retired, zouk falls back to `files.json` when a
server doesn't offer a WebDAV listing, so this release works with both
the old and the new server.

No other user-facing changes.
